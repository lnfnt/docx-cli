docx-cli// headless word for ai agents

Apache-2.0 v0.1.3 526 tests passed ECMA-376 100% ISO/IEC 29500 zero office runtime pure python

Headless Microsoft Word промышленного уровня для автономных AI-агентов и LLM. Инструмент не эмулирует Word — он компилирует настоящий OpenXML (ECMA-376 / ISO/IEC 29500) на уровне байтовой архитектуры OPC ZIP-пакета. Без LibreOffice, без MS Office, без системных GUI-зависимостей. Детерминировано: один вход — один байтовый результат.

Почему не markdown-конвертер

Большинство инструментов сборки .docx в мире агентов — это примитивные конвертеры Markdown в плоский текст, обёртки над LibreOffice или скрипты, ломающие форматирование при подстановке плейсхолдеров. docx-cli собирает настоящие структуры Word:

Никаких суррогатов

Сноски — в word/footnotes.xml, комментарии — в word/comments.xml, списки — в word/numbering.xml. Там, где их ждёт Word.

Умный рецензент

Агент проводит аудит документа и возвращает файл с видимой историей правок — Track Changes и комментарии на полях с автором и датой.

Живая шаблонизация

Подстановка {{var}} устойчива к дроблению строк на элементы <w:r> офисным редактором. Табличные циклы, условные блоки, вложенные ключи.

№Домен Word (ECMA-376)Что даёт агентам
1Геометрия и разделы — ориентация, поля, колонтитулы, газетная многоколоночная вёрсткаАльбомные таблицы в середине текста, колонки.

3Абзацы — выравнивание, интервалы, красная строка, keepWithNext, защита от висячих строкВёрстка по ГОСТ и корпоративным стандартам.
4Списки и нумерация — многоуровневая иерархия в numbering.xml с автосбросом уровнейНастоящие списки Word вместо текста с пробелами.
5Таблицы — colspan/rowspan, точные ширины, заливка, границы, повтор шапкиСметы, акты, спецификации произвольной сложности.
6Графика (DrawingML) — PNG/JPEG/GIF, масштабирование под геометрию листа, подписиДиаграммы, печати, иллюстрации без вылета за поля страницы.
7Динамические поля — PAGE, NUMPAGES, автообновление в settings.xmlАктуальные номера страниц при открытии в Word.
8Ссылочный аппарат — сноски, концевые сноски, авто-TOC, закладки, перекрёстные ссылкиАкадемические статьи, аналитические записки, договоры.
9Интерактивные формы (SDT) — чекбоксы, выпадающие списки, селекторы даты, текстовые поляАнкеты, чек-листы согласования, бланки.

11Безопасность — аудит скрытых prompt-инъекций, защита от редактирования (readOnly/comments/forms)Защита от враждебных промптов и правок готового документа.
12Математика (OMML) — векторный компилятор формул: дроби, корни, степени, суммы, интегралыФормулы рендерятся как уравнения Word (Cambria Math), не картинками.
13Вложения — файлы внутри zip-пакета (word/attachments/) с метаданными и SHA-256Самодостаточные документы-контейнеры с исходными данными.
14Шаблонизатор — Run-Reconciliation, вложенные ключи, табличные циклы, условные блокиТиповые бланки и договоры из JSON произвольной формы.

Гарантии

Детерминизм

Одинаковый вход даёт одинаковый байтовый выход — генерация воспроизводима в контурах с контролем целостности.

499 тестов

Полный набор проверок доменов; пакет собирается из явного списка исходников.

Чистый Python

Ноль нативных зависимостей офисных рантаймов — работает в headless-контурах, CI и изолированных агентах.

Ревью-контур

Агент читает чужой .docx, возвращает правки как Track Changes — человек видит, что именно предлагал агент.
